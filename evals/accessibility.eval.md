# Accessibility Evaluation (WCAG 2.1 AA)

## Purpose

Assess baseline accessibility readiness of generated UX/UI outputs and implementation guidance.

## Scope

- Contrast and visual clarity.
- Keyboard navigation support.
- ARIA and semantic guidance.
- Error and state communication.

## Checklist

- [ ] Contrast criteria target is explicit (4.5:1 normal text, 3:1 large text).
- [ ] Keyboard flows are documented (Tab, Enter, Escape, arrows).
- [ ] ARIA roles and labels are specified for interactive patterns.
- [ ] Error states provide message + recovery action.
- [ ] States are not represented by color only.
- [ ] Touch targets target 44x44 minimum.

## Scoring

- 0 = not addressed
- 1 = partially addressed
- 2 = addressed with clear acceptance criteria

Maximum score: 12
Pass threshold: 10
