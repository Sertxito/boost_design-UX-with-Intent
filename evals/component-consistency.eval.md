# Component Consistency Evaluation

## Purpose

Verify component definitions and usage guidance are consistent across agents, skills, and templates.

## Scope

- Naming consistency.
- Variant consistency.
- Documentation consistency.
- Cross-framework style guidance.

## Checklist

- [ ] Component names match across docs and skills.
- [ ] Required variants are defined (default, hover, focus, disabled, error, loading).
- [ ] Storybook guidance aligns with component templates.
- [ ] React and Vue styling skills expose equivalent conceptual coverage.
- [ ] Accessibility requirements are attached to each core component family.

## Scoring

- 0 = inconsistent
- 1 = partially consistent
- 2 = consistent and verifiable

Maximum score: 10
Pass threshold: 8
