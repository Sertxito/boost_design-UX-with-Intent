# Example: Hallmark to BoostDesign Flow

## Goal
Use Hallmark for visual exploration and complete a governed UX handoff.

## Step 1: Explore a distinctive visual direction
Prompt:

```text
Usa Hallmark para proponer una direccion visual para el hero de una landing SaaS B2B.
```

## Step 2: Normalize into design tokens
Prompt:

```text
@design-system-architect transforma esta propuesta visual en tokens semanticos y patrones reutilizables.
```

## Step 3: Run UX governance checks
Prompt:

```text
@ux-ui-expert valida accesibilidad WCAG AA, consistencia de componentes y cobertura de estados sobre esta propuesta.
```

## Completion Criteria
- [ ] Output includes clear visual rationale.
- [ ] Output includes token mapping.
- [ ] Output includes accessibility and consistency validation.
- [ ] Output includes remediation steps before implementation.
